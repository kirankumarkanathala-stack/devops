The big picture

You rent a small Linux computer from AWS, connect to it from your laptop, and control it by typing commands. That is the whole session.

  1. Launch an EC2 server
  2. Open port 22
  3. Log in with an SSH key
  4. Run Linux commands
  5. Automate it later

Learn each task by hand first. Once you understand it, tools like Terraform, Ansible, and CI/CD pipelines will make sense.

EC2: your server in the cloud

EC2 is AWS's service for renting virtual machines (called instances).

RegionN. Virginia (us-east-1)
Operating system (AMI)Amazon Linux, part of the Red Hat family
Sizet3.micro: 2 vCPUs, 1 GB RAM, free tier
Disk8 GB root volume
LoginYour imported SSH key pair

Watch the bill. The free tier gives roughly 100 to 200 in credits for about 2 to 3 months. Always terminate instances when you finish practicing.

Security group: the server's firewall

Nothing gets in unless a rule allows it. For SSH you add one inbound rule:

Type and portSSH, port 22
Source: My IPSafest. But your home IP changes over time, so you may get locked out later.
Source: Anywhere0.0.0.0/0. Always works, but the whole internet can reach the port.
OutboundEverything is allowed by default

Log in with SSH

SSH uses a key pair instead of a password: a public key that goes to AWS, and a private key that stays with you.

  1. Create the key pair on your computer

    Makes mykey (private) and mykey.pub (public)

  2. Import the public key into AWS Upload mykey.pub in the EC2 console under Key pairs, then pick it when you launch the instance. Never share the private key.
  3. Connect

    -i points to your private key. ec2-user is the default user on Amazon Linux.

  4. Leave when done

    Closes the SSH session

Error about a missing key file? SSH cannot find the key from where you are. Give the full absolute path, like ssh -i /home/you/mykey ec2-user@<public-ip>.

Absolute vs relative paths

Absolute

Starts at the root /. Works from anywhere, so it is the reliable choice.

/home/ec2-user

Relative

Starts from the folder you are in.

  • .. means the parent folder
